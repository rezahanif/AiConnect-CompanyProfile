# AiConnect Landing Page — Figma Make Design Brief / PRD

## 0. Purpose

Create the AiConnect company/product landing page based on the supplied GitHub landing-page reference screenshot, while replacing all GitHub-specific branding, messaging, products, imagery, and calls to action with AiConnect's own product identity.

The page should feel:

* premium;
* technical;
* modern;
* trustworthy;
* AI-native;
* engineering-oriented;
* visually impressive without becoming visually noisy.

The reference screenshot is the **visual inspiration and structural baseline only**.

Do NOT copy GitHub branding, text, logos, product names, or proprietary interface content.

The final design should communicate:

> AiConnect connects AI agents to real engineering software and preserves project progress across AI models and tools.

---

# 1. Primary Goal

The landing page should make a new visitor understand these five things within one page:

1. AiConnect lets AI work with real engineering and professional software.
2. The user's project progress can persist across different AI models.
3. AiConnect supports many connectors/software integrations.
4. AiConnect provides engineering-specific skills and guided workflows.
5. The user can download the desktop app for Windows, macOS, or Linux and start a 7-day free trial.

Primary conversion:

```text
Download AiConnect
```

Secondary conversion:

```text
Explore connectors / learn more
```

Third conversion:

```text
Contact developer / request a connector
```

Use subtle animation.

Suggested:

# 25. IMPORTANT PRODUCT CLAIM RULE

Do not claim functionality that is not actually implemented.

Examples:

Do not say:

> Works with every AI model

Instead:

> Works with compatible AI agents and models.

Do not say:

> Supports every engineering application

Instead:

> Connect engineering software through an expanding connector library.

Do not say:

> Never lose context

Instead:

> Preserve project progress across AI sessions.

Do not say:

> Fully autonomous engineering

unless the product actually supports that claim.
